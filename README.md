# ALUVA — Examen Final Diseño Web

Proyecto final de la asignatura **Diseño Web (DSWE0623)**.

## Base del proyecto

El sitio corresponde a la continuidad del trabajo realizado en la Evaluación N.º 3:
migración del sitio corporativo ALUVA a un template Bootstrap 4 Creative Onepage.

## Objetivo del examen

Entregar una versión final funcional y responsiva, con HTML, CSS, JavaScript y eventos,
publicada en GitHub y desplegada en Netlify.

## Tecnologías

- HTML5
- CSS3
- Bootstrap 4
- JavaScript
- jQuery/Bootstrap JS incluido en `js/plugins.js`
- PDF mediante `<embed>`
- Recursos gráficos locales

## Funcionalidades incorporadas para la versión final

- Validación del formulario de personalización mediante evento `submit`.
- Generación dinámica de solicitud para WhatsApp.
- Validación del formulario de contacto mediante JavaScript.
- Apertura del cliente de correo mediante `mailto`.
- Galería interactiva mediante evento `click` y modal Bootstrap.
- Botón "volver arriba" mediante eventos `scroll` y `click`.
- Cierre del menú móvil al seleccionar una sección.
- Año del footer actualizado automáticamente con JavaScript.
- Diseño responsive para móviles, tablets y escritorio.

## Ejecución local

Abrir `index.html` en un navegador. Para una prueba más completa se recomienda utilizar
un servidor local, por ejemplo la extensión Live Server de Visual Studio Code.

## Publicación

Completar los enlaces reales de GitHub y Netlify en el archivo
`ENLACES_GITHUB_NETLIFY.txt` después de realizar las publicaciones.
